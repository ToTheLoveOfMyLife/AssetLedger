# Rescue Animal System — Java OOP Coursework

An early Java object-oriented programming exercise centered on inheritance and managing multiple animal types in a console application.

## Concepts practiced
- Classes and inheritance
- Collections with `ArrayList`
- Object construction
- Console input
- Validation logic
- Basic application flow

## Project status
This repository is preserved as coursework and learning history. Some methods in the original assignment remain incomplete, which is intentionally documented rather than presented as production-ready software.

> This project is not representative of my current project scope or engineering level.
